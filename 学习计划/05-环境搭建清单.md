# 环境搭建清单（照着做，第 1～14 天分步完成）

> 我已经检查过这台电脑：**Node.js 已装好**，**Git 未装**，**Godot 未装**。
> 原则：**一次只装一个东西，装完立刻验证，验证不过不装下一个。**

---

## A. 第 1 天：Git + GitHub（最重要，先做这个）

### A1. 装 Git for Windows
1. 打开 https://git-scm.com/download/win
2. 下载 **64-bit Git for Windows Setup**
3. 安装时**全部保持默认，一路 Next**（默认选项就是给小白用的）
4. 装完**重启一次电脑**（让命令行识别新程序）

**验证**：按 `Win + R`，输入 `powershell`，回车。在黑窗口里输入：
```powershell
git --version
```
出现类似 `git version 2.4x.x.windows.1` 就成功了。**如果提示"不是内部或外部命令"，说明没装好或没重启，重装一次。**

### A2. 注册 GitHub
1. 打开 https://github.com → Sign up
2. 用户名建议：小写英文 + 数字，别用中文，别用奇怪符号
3. **邮箱必须真实**（要收验证码），建议用常用邮箱
4. 注册后去邮箱点验证链接

### A3. 装 GitHub Desktop（图形界面，小白必备）
1. 打开 https://desktop.github.com/
2. 下载安装，用刚注册的账号登录
3. 登录后点 `File → Options → Git`，确认 Name / Email 已填（这是提交记录用的）

**为什么用 GitHub Desktop 而不是命令行**：你现在的阶段不需要背 `git` 命令。可视化界面能看到"改了哪些文件、要不要提交"，理解成本低得多。命令行等第 6 周再慢慢接触。

### A4. 配置 Git 基础设置
在 PowerShell 里依次运行（把名字和邮箱换成你的）：
```powershell
git config --global user.name "你的GitHub用户名"
git config --global user.email "你的GitHub注册邮箱"
git config --global core.autocrlf true
git config --global init.defaultBranch main
```

> `core.autocrlf true` 是 Windows 上必须的，否则以后换行符会让 Git 认为你改动了所有文件。

### A5. 在 GitHub 网站上创建学习仓库
1. GitHub 右上角 `+` → `New repository`
2. 名称：`ai-game-learning`
3. 选择 **Public**（公开，以后可以当作品集）
4. 勾选 `Add a README file`
5. 点 `Create repository`

**验证**：在 GitHub Desktop 里 `File → Clone repository → GitHub.com`，能看到 `ai-game-learning`，克隆到你能找到的文件夹（建议 `D:\dev\ai-game-learning`）。

✅ **A 部分完成标志**：GitHub Desktop 里能看到你的仓库，本地文件夹里有 README.md。

## B. 第 1 周：VS Code（写 JS / 看代码）

1. 打开 https://code.visualstudio.com/ → 下载 Windows 版 → 安装（默认即可）
2. 装完打开，按 `Ctrl+Shift+X` 打开扩展面板，装这三个：
   - **Chinese (Simplified) Language Pack**（中文界面）
   - **Prettier - Code formatter**（自动排版）
   - **GitLens**（看代码是谁什么时候改的，很有教育意义）

**为什么装 VS Code**：Godot 自带编辑器写 GDScript 够用，但写 JS、看别人的代码、批量搜索关键词时 VS Code 强得多。

## C. 第 2 周：Godot 引擎

### C1. 下载
1. 打开 https://godotengine.org/download/windows/
2. 下载 **Godot Engine 4.x（Standard / 标准版）的 .zip**，**不要下 .NET / C# 版本**（你需要 C# 才能用，而我们只用 GDScript）
3. 解压到一个**纯英文、无空格**的路径，例如 `D:\dev\Godot\`
   > ❗ 千万不要放在 `C:\Program Files` 或中文路径下，Godot 有时会出问题
4. 里面的 `Godot_v4.x-stable_win64.exe` 就是引擎本体，双击即用。**建议右键 → 发送到 → 桌面快捷方式**

### C2. 确认版本
打开后右下角会显示版本号，记到 `学习日志.md` 里。**遇到任何教程，先确认它的 Godot 版本和你一致**——Godot 3 和 Godot 4 的代码几乎不通用，这是新手最大的坑。

### C3. 编辑器语言设为中文（可选，但建议初期开）
`Editor → Editor Settings → General → Interface → Editor → Language → 简体中文` → 重启编辑器。
> 建议：**界面用中文，但代码里所有变量名坚持用英文**。用中文变量名以后会遇到莫名其妙的编码问题。

### C4. 装官方模板项目（重要）
`AssetLib` 标签页 → 搜索 `2D Platformer` / `Dodge the Creeps` → 下载安装。
或者直接从 GitHub 拿官方 demo 合集（见 `02-GitHub学习项目库.md` 的 #1）。

## D. 第 2 周：AI 编程 Agent 工具

你在网页上和 AI 聊天，只能得到"复制粘贴的代码"。**Agent 工具能直接读写你项目文件夹里的文件、运行命令**——这才是真正的 AI 编程。

### D1. 先确认 Node.js（你这台电脑已经有了）
在 PowerShell 里验证：
```powershell
node -v
npm -v
```
两个都应该输出版本号。如果 `node -v` 报错，说明环境变量没配好，需要把 `D:\124\New Folder` 加入系统 PATH。

### D2. 可选的 Agent 工具方向（第 7 周才需要，先了解）
- **命令行式 Agent**：安装后在项目文件夹里运行，它能读你的文件、改代码、跑测试。各家命名不同（Codex 类工具、Claude Code 类工具）。
- **IDE 内置式**：在 VS Code 里装 AI 插件，边写边补全。
- **本机工作台式**：你现在用来读这份文档的这个工具，本身就属于这一类——它已经在你的项目文件夹里了。

**关键概念**：不管哪种，用法都一样——**给它一个明确任务 + 限定它只能改哪些文件 + 让它跑一遍验证**。你在 `03-提示词库.md` 里学的提示词，全部可以直接用在 Agent 上。

### D3. 申请 API Key（第 7 周做，先知道去哪）
- OpenAI：https://platform.openai.com/api-keys
- Anthropic（Claude）：https://console.anthropic.com/
- DeepSeek：https://platform.deepseek.com/

**规则（重要）**：
1. API Key 等于钱袋子，**绝对不能**发到聊天里、不能提交到 GitHub、不能写在代码里。写在 `.env` 文件里，并把 `.env` 加进 `.gitignore`。
2. 每个平台**先充值最小金额**（比如 $5），然后设置**用量上限（Usage Limit）**，防止脚本死循环烧钱。
3. 第一次调用 API，先用最便宜的模型跑通流程。

## E. 第 6 周：美术与素材工具（免费为主）

| 用途 | 工具 | 说明 |
|---|---|---|
| 免费素材下载 | **itch.io**（https://itch.io/game-assets） | 独立游戏素材最大聚集地，注意看每个素材的 License |
| 免费素材下载 | **Kenney.nl** | 全部 CC0（可商用、无需署名），小白最安全的选择 |
| 像素画编辑 | **Aseprite**（付费）/ **LibreSprite**（免费分支）/ **Piskel**（网页版） | 改素材、做动画帧 |
| 矢量图 | **Inkscape**（免费） | 做 UI、图标 |
| AI 生图 | ChatGPT Images（网页版即可） | 出概念图、UI 草图、图标。**注意：AI 生成图的版权归属和商用条件每个平台不同，商用前必须查最新条款** |
| 音频 | **sfxr / jsfxr**（网页版）、**freesound.org** | 8-bit 音效一键生成 |

> **版权红线（第 6 周会详细练）**：任何素材使用前，必须找到它的 License 并回答三个问题：
> ① 能商用吗？ ② 要署名吗？ ③ 能修改吗？
> 有一个答不上来，就换素材。很多新手做完游戏不敢发布，就是卡在这里。

## G. 新手环境三大坑（提前避开）

1. **路径里有中文或空格** → Godot、Node 脚本、命令行工具都可能出错。
   正确：`D:\dev\my-game` ❌错误：`C:\Users\我 的文档\游戏 项目`
2. **Godot 3 和 4 的教程混着看** → 报错满天飞，还找不到原因。**只学 4.x**。
3. **把 API Key / 密码提交到 GitHub** → 会被爬虫秒扫，几小时内被盗刷。记住：**凡是密钥，一律 `.env` + `.gitignore`**。
