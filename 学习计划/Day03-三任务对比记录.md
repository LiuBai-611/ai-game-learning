### 任务 A（翻译）—— 一次通过，但有一处母语级硬伤

> Starfall Scavenger is a 2D pixel-art roguelike. You play as a scavenger drifting between abandoned space stations: every run generates a random map where you collect parts, upgrade your ship, and fight off rogue security robots. The game is built around the short-run experience — a run lasts 10 minutes, death means starting over, but you always carry out a little permanent upgrade progress. Perfect for fans of The Binding of Isaac and Enter the Gungeon.

| 检查点 | 结果 |
|---|---|
| "局" → `run` | ✅ `every run` / `a run lasts` |
| "永久强化"没丢 | ✅ `permanent upgrade progress` |
| `roguelike` 保留原词 | ✅ |
| 两个游戏名用官方英文名 | ✅ The Binding of Isaac / Enter the Gungeon |
| 没自己加营销词 | ✅ |

**⚠️ 但有一处硬伤**：`carry out` 是"执行（任务）"，"带走一点资源"应该是 **`carry over`**（或 `carry away`）。
**这种错不报错、通读还挺顺**，母语者一眼看出不对——**和任务 B 的跳跃符号是同一类问题：机械活里也藏着"看起来对但其实错"的地方。**

### 附：这次盲测顺手抓出了**我自己**写错的一处

原稿在"干扰项"那节写的是"`is_on_floor()` 放在 `move_and_slide()` 之前会让开局第一下跳跃失效（所以必须放在之后）"——**说过头了**。
