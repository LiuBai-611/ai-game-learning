# Day 02 · 模型分级：建立"什么任务派谁"的判断力

> 今天的目标不是"背下模型清单"，而是建立一种**不会过期**的能力：拿到一个任务，知道该派哪一档模型。
> 预计 90 分钟。

---

## 为什么这个能力不会过期

模型名字每两三个月就换一批。你今天背下"GPT-6.5-Luna"，三个月后可能就没了。

但**"任务分档"这件事是稳定的**：永远有贵的、中的、便宜的；永远有擅长推理的、擅长速度的。

**你练的是分类能力，不是记忆能力。**

---

## 第一步：认识"三档模型"（20 分钟）

任何一家模型服务，本质都提供**三个档次**：

| 档位 | 特征 | 什么时候用 | 判断口诀 |
|---|---|---|---|
| **旗舰档** | 最强推理、最贵 | 复杂 bug、架构设计、长代码重构、想不清楚的难题 | **"这问题我想不明白"** → 旗舰 |
| **主力档** | 平衡，价格适中 | 日常问答、写代码、解释概念、改文案 | **"我知道要什么，只是要它帮我做"** → 主力 |
| **轻量档** | 最快最便宜 | 翻译、格式转换、摘要、分类、批量处理 | **"这活重复、机械"** → 轻量 |

**关键认知**：90% 的日常任务，**用轻量档就够了**。新手最常见的浪费是——拿旗舰模型问"帮我把这段翻译成英文"。

## 第四步：用"追问三连"验证（20 分钟）

### 什么是追问三连

AI 的第一遍回答通常只是"及格线"。真正有用的信息在追问里。**三句万能追问**：

```
1. 再具体一点
2. 给我一个例子
3. 如果我这样做会怎样
```

### 今天的练习

选一个你真想知道的问题，比如：

```
我在学做游戏，不会编程。GDScript 和 Python 有什么区别？
```

拿到回答后，**依次追问这三句**，把每次的回答都记下来，观察：

- 第一遍 vs 追三遍后，信息量差多少？
- 哪一句追问带来的价值最大？

> **这个练习会让你发现一件事**：很多人觉得"AI 答得不好"，其实只是**没追问**。

## 今日核心认知（记住这三句）
