## 三、DeepSeek 官方 API 档（如果你接了自己的 Key）

数据来源：[DeepSeek 官方定价页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)
单位：元 / 百万 tokens。**空闲时段价格 = 高峰的一半**（高峰：工作日 9:00-12:00、14:00-18:00）

| 模型 | 输入（未命中） | 输出 | 上下文 | 视觉 | 用它做什么 |
|---|---|---|---|---|---|
| **deepseek-flash** | 1～2 元 | 4～8 元 | 1M | ✅ 支持 | 日常主力、批量处理、**需要传图的场景** |
| **deepseek-v4-pro** | 4.5～9 元 | 13.5～27 元 | 1M | ❌ 不支持 | 复杂推理、长代码重构 |

**这张表里能读出的两条实用结论**：

1. **输出比输入贵得多**（Flash：输入 1 元 vs 输出 4～8 元）→ **让 AI 少说废话能省钱**。这就是为什么提示词里写"用 200 字回答"不只是为了好看。
2. **你接的 API 和网页版是两套计费** → 网页版免费，API 扣钱。别以为"DeepSeek 是免费的"。

## 三点五、通义千问（阿里云百炼）官方价格

数据来源：阿里云开发者社区公布的最新计费明细（华北2 北京地域，中国内地部署）
单位：元 / 百万 tokens。**"思考模式"的输出通常贵得多**（因为思维链也算输出）。

### 三档对照（这是通义版的"分级"）

| 档位 | 代表模型 | 输入 | 输出 | 用途 |
|---|---|---|---|---|
| **旗舰档** | **qwen3.8-max** | 12 元 | **36 元** | 复杂推理、专业代码、长文档 |
| | qwen3.8-max-prime（顶配） | 24 元 | **72 元** | 官方原话"对智能水平有极致要求" |
| **主力档** | **qwen3.5-plus** | **0.8 元** | **4.8 元** | 日常高频、性价比 |
| | qwen3.6-plus | 2 元 | 12 元 | 同上，更新版本 |
| | qwen-plus（非思考 / 思考） | 0.8 元 | **2 元 / 8 元** | ← 注意思考模式贵 4 倍 |
| **轻量档** | **qwen-flash** | **0.15 元** | **1.5 元** | 机械任务、批量处理 |
| | qwen-turbo | 0.3 元 | 0.6 元 | 更便宜 |
| **专用档** | qwen3-coder-flash | 1 元 | 4 元 | 写代码 |
| | qwen3-coder-plus | 4 元 | 16 元 | 复杂代码 |
| | qwen-long | **0.5 元** | **2 元** | 超长文本、文档摘要 |
| | qwen3-vl-flash | 0.15 元 | 1.5 元 | **图片理解**（最便宜） |
| | qwen-vl-ocr | 0.3 元 | 0.5 元 | OCR 文字识别 |

### 从这张表能读出的四条规律

**1. 旗舰和轻量差 48 倍**
`qwen-flash` 输出 1.5 元 vs `qwen3.8-max-prime` 输出 72 元。**同样的活，选错档位贵近 50 倍。**

**2. "思考模式"是隐藏成本**
`qwen-plus` 非思考输出 2 元，思考模式输出 **8 元（4 倍）**。
因为**思维链（推理过程）也按输出计费**。这就是为什么 WorkBuddy 里要区分 `Chat alias` / `Reasoner alias` —— **不是所有问题都值得开思考**。

**3. 阶梯计费会"整单升级"**
部分模型按**单次请求的输入长度**分档，且**整次请求的所有 token 都按所落档位的单价算**，不是只算超出的部分。

> 例：0-32K 档输入 2.5 元，32K-128K 档输入 4 元。你塞了 100K 输入 → **全部按 4 元算**，不是"前 32K 按 2.5 元"。
> **实践结论**：上下文塞越长，单价可能整体跳档。**该开新对话就开新对话。**

**4. 有一堆"降本开关"**（知道就好，现在不用急着用）

| 开关 | 效果 |
|---|---|
| **上下文缓存** | 命中缓存时输入只按 **10%** 计费（首次创建按 125%） |
| **Batch 调用** | 输入输出**全部半价**，但只适合离线批量任务 |
| **夜间优惠（Night Plan）** | 22:00 后调用，部分模型**低至 4 折** |
| **免费额度** | 新用户赠超 **1 亿 tokens**（90 天）；每个模型再单独送 100 万 |

> 💡 **对你最有用的一条**：新用户开通即赠 **超 1 亿免费 tokens，90 天有效**。
> 这意味着你现在就能**零成本**把通义、千问的各种模型都试一遍 —— 正好是 Day 02 要做的事。
> 控制台里记得打开 **"免费额度用完即停"**，防止意外扣费。

## 三点六、豆包（火山方舟）

⚠️ **我没能取到官方价格数据。** 火山方舟的定价页是 JavaScript 动态渲染的，抓取工具拿不到内容。

**你需要自己打开这个页面看**（能打开就说明你的网络没问题）：
https://www.volcengine.com/docs/82379/1099320

**但我查到一个重要的程序性区别**（来自[第三方文档](https://www.hcfy.ai/en/docs/services/doubao/)，该文档自己也声明"以火山方舟平台说明为准"）：

> **豆包的模型不能直接用，必须先"创建接入点"才能调用。**
> 流程：注册 → 开通模型 → 创建 API Key → **创建推理接入点**（拿到 `ep-xxxxx` 形式的接入点 ID）→ 才能调用。

这和 DeepSeek / 通义"拿到 Key 就能用"不一样，**多一个步骤**。你以后想把豆包接进 WorkBuddy 自定义模型时，会撞到这一步。

> ⚠️ 该文档还提到 `Doubao-lite-32k` 输入 0.3 元 / 输出 0.6 元、`Doubao-pro-32k` 输入 0.8 元 / 输出 2 元。
> **但这是较早期的模型，很可能已过时。不要拿这两个数字做决策**，去官网看当前的 Seed 系列。

## 四、决策树（贴在心里，遇到任务先过一遍）

```
拿到一个任务
  │
  ├─ 机械重复？（翻译、格式化、摘要、分类）
  │     └─→ 免费档（DeepSeek Flash / Hy3）
  │
  ├─ 我知道要什么，只是要它帮我做？（写代码、解释概念、改文案）
  │     └─→ Luna（0.14x）或 Terra（1.39x）
  │
  └─ 我想不明白 / 已经卡住很久？
        └─→ 先花一次 Astra（6.67x）
              │
              └─ 还没解决？→ 换一家问（交叉验证思路）
```

**最后一条很重要**：卡住时，"**换个模型问同一个问题**" 往往比 "**同一个模型问十遍**" 有效得多。

## 五、三条使用纪律

1. **默认用最便宜的能解决问题的档位**。觉得不够再往上加，不要一上来就上旗舰。
2. **不确认的结论不要采纳**。模型说的事（尤其版本号、价格、政策）**必须去官网核实**。
   > 这条是我今天用两次错误换来的教训：我说"GPT-6 astra 大概不存在"是错的，因为**我没去核实就下了判断**。
3. **省钱不等于省时间**。如果一个问题 Astra 一次解决、Flash 问了五次还没解决，那 Astra 更划算。
